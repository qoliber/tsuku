4. HTML Generation with XSS Protection:
<div class="comment">
  <h3>John &lt;script&gt;alert(&quot;XSS&quot;)&lt;/script&gt; Doe</h3>
  <p>This is a &lt;strong&gt;great&lt;/strong&gt; product &amp; I love it!</p>

5. URL Encoding for Query Parameters:

=== Summary ===
Number formatting functions:
- @number(value, decimals, decPoint, thousandsSep)
- @round(value, precision)
- @ceil(value), @floor(value), @abs(value)

Escaping functions:
- @html(text) - HTML escaping (XSS protection)
- @xml(text) - XML escaping
- @json(text) - JSON escaping
- @url(text) - URL encoding
- @csv(text) - CSV escaping with quotes
- @escape(text, type) - Generic escape function
